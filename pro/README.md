# Farvist Pro

> The framework is free. **Pro** is the shortcut.

Farvist (the framework) is MIT-licensed and free forever. **Farvist Pro** is an optional,
commercially-licensed pack of premium blocks, full templates and design files built on top of it —
the same open-core model as Tailwind Plus.

**Status: early access.** Pro is being built in the open. This folder holds a couple of **free
samples** so you can judge the quality; the rest ships to early-access buyers as it lands (it is *not*
committed to this public repo).

### For the maintainer — how to actually sell this

1. **Storefront:** the cheapest path is a hosted checkout — **Lemon Squeezy**, **Gumroad**, **Polar.sh**
   or **Stripe Payment Links**. They handle tax/VAT and license-key delivery for one-time digital goods.
2. **Delivery:** zip the Pro pack + Figma file; the checkout emails a download link + a license key.
3. **License gating:** keep Pro in a private repo; grant buyers access, or just ship a versioned zip.
4. **Funnel:** free framework + docs (`index.html`) → `marketing.html` pricing → checkout.
5. **Be honest:** only advertise what buyers actually receive today. Use the early-access framing for the
   rest, and ship the free framework + build GitHub stars and traffic *before* launching Pro.
