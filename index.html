Installation guide ↗

Use a CDN

Add this to your HTML <head>. No tooling required.

<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/farvist@1/dist/farvist.min.css">
<!-- Optional: interactive components -->
<script defer
  src="https://cdn.jsdelivr.net/npm/farvist@1/assets/farvist.js"></script>

Or install with npm

Install with npm install farvist, then import:

import 'farvist/dist/farvist.min.css';
// Optional: tabs, modals, copy buttons & themes
import 'farvist/assets/farvist.js';
